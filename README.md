> A simple static landing page for BiteBox – a fictional food delivery restaurant, built using pure HTML.

---

### 📌 Project Overview
This is the first version of the BiteBox website.  
It focuses on creating a basic single-page layout using fundamental HTML tags to display restaurant information, featured dishes, offers, and opening hours.

---

### ✨ Features
- Restaurant branding with highlighted title
- Welcome section
- About section
- Today’s Featured Dishes
- Special Offer section
- Opening Hours
- Copyright footer

---

### 🛠️ Skills Demonstrated
- Basic HTML5 structure
- Headings and paragraphs
- Text formatting (`strong`, `em`, `mark`, `sup`)
- Horizontal rules for section separation
- Creating a clean single-page layout

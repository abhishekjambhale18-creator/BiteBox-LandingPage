### 📌 Project Overview
BiteBox is a simple single-page restaurant website created as part of my Web Development learning.  
It includes basic sections like welcome message, about, featured dishes, offers, and opening hours using fundamental HTML tags.

---

### ✨ Features
- Restaurant branding with highlighted title
- Welcome section
- About section
- Today's Featured Dishes
- Special Offer section
- Opening Hours
- Copyright footer
